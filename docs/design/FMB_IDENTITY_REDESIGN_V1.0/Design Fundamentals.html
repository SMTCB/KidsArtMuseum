Direção A · Cubo Branco — Direção C · Corredor

Referência rápida dos tokens visuais de cada direção: paleta, tipografia, sistema de molduras, botões e espaçamento. Ambas partilham a mesma estrutura de layout e o mesmo sistema de molduras por meio (carvalho / preto / latão / caixa funda) — o que muda é a voz tipográfica, o uso de cor de destaque e a densidade da legenda.

Direção A — Cubo Branco

Clássico · Neutro · Sem cor de destaque
Galeria de museu tradicional: paredes neutras, tipografia serifada com itálico, mono para metadados. Nenhuma cor de destaque — o contraste vem da tipografia e das molduras, nunca de um acento cromático.

Direção C — Corredor

Minimal · Espaço negativo · Acento dinâmico por obra
Corredor de galeria contemporânea: sans-serif, espaço em branco generoso, molduras finas quase invisíveis. Cada obra recebe uma cor de acento própria (barra de cor junto ao título) — o único lugar onde a cor aparece deliberadamente.
