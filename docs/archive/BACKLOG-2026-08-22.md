# Backlog

Every known work item. `SPRINTS.md` decides what happens when; this file is the pool.

**IDs are permanent.** Reference them in commits (`FND-02: rotate PAT`) and never reuse a
retired one.

**Size:** S = under an hour · M = a few hours · L = a day or more · XL = multi-day, needs breaking down.

| Status | Meaning |
|---|---|
| `todo` | Not started |
| `now` | In the active sprint |
| `done` | Shipped and verified |
| `blocked` | Waiting on an ADR or an external dependency |
| `icebox` | Real, but not while ADR-0004 is open |

## QUA — Live-site quality

What a visitor actually experiences today.

| ID | Item | Size | Status | Notes |
|---|---|---|---|---|
| QUA-01 | **Image weight: generate thumbnails + `srcset`** | L | `todo` | The hallway ships **25 MB** of JPEGs. Every frame loads the full-resolution original into a thumbnail-sized box — `era-uma-vez.jpeg` alone is 4.5 MB, and 8 of 12 files are over 1.3 MB. Highest user-facing impact item in this backlog, and it gets worse with each artwork added. Extend `scripts/optimize.js` to emit a wall-sized derivative. |
| QUA-02 | Ship production React builds | S | `todo` | `index.html` loads `react.development.js` and `react-dom.development.js` in production. Two-line fix, no downside, independent of ADR-0008. |
| QUA-03 | Remove in-browser Babel | L | `blocked` | Nine JSX files transpile on every page load. Blocked on ADR-0008. |
| QUA-04 | Smoke test + CI | M | `todo` | Zero automated verification today; every change is eyeballed. A headless check would catch the class of bug that matters: every `art.anim` resolves in `window.ANIMS`, every `HALLWAY_ORDER` id exists, every `src` file exists, every required schema field present. All four were verified by hand during the assessment — automate that. |
| QUA-05 | Verify mobile layout after the image work | S | `todo` | Mobile grid was fixed in `724d6cb` but is untested since the Sala de Experimentação landed. |
