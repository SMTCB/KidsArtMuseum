# Sprint Plan

Two-week sprints, sized for evenings-and-weekends rather than full-time work. Each sprint
has **one goal** — if only one thing ships, it should be that.

The arc: **stabilize → polish what exists → decide → build the leap.**

Item IDs refer to `BACKLOG.md`.

---

## Sprint 0 — Ground control · 2026-08-22 → 2026-09-05

> **Goal: nothing important is lost, and the repo tells the truth about itself.**

Short and unglamorous. Everything here is cheap now and expensive in six months. Coming
back from a break is the right moment for it, because the cost of *not* doing it is exactly
what made this pickup harder than it should have been.

## Sprint 1 — The museum people actually see · 2026-09-05 → 2026-09-19

> **Goal: the hallway loads fast and looks right on a phone.**

The site currently ships **25 MB of images** to render eleven thumbnails. Whatever ADR-0004
decides, this is wrong, and it is the gap between "a nice project" and "something you send
to a grandparent without apologising."

| ID | Item | Size |
|---|---|---|
| QUA-01 | **Thumbnails + `srcset`** | L |
| QUA-02 | Production React builds | S |
| QUA-04 | Smoke test (schema, anim keys, hallway order, asset paths) | M |
| QUA-05 | Verify mobile after the image work | S |
| FND-07 | Reconcile `ART_GUIDE` §5a with the 44 registered anims | M |
| — | **Decide ADR-0008** (build step) | — |

**Done when:** hallway initial payload is under ~2 MB, the smoke test runs green, and the
gallery has been opened on a real phone.

**Measure first.** Record the current load time before touching anything, so the improvement
is a number rather than a feeling.

## Working agreements

- **One goal per sprint.** If it does not serve the goal, it waits.
- **Decisions are sprint work.** An ADR on the board is a deliverable like any other.
- **Definition of Done includes docs** — see `DOCUMENTATION_GUIDE.md` §5.
- **Verify in a browser before committing.** No build step means no compiler to catch you.
- **Re-plan at the sprint boundary**, not mid-sprint. Update this file and bump `last_reviewed`.
